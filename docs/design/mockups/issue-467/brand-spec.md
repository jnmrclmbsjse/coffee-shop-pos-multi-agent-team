# UCM Coffee Studio admin visual system

The Journal extends the shipped light admin system: cool neutral surfaces, a single green action accent, compact system typography, 6-10px radii, and borders rather than decorative elevation.

## Tokens

The six core visual tokens are shipped in `BRIEF.md` and used unchanged:

- `--bg: oklch(98% 0.005 250)`
- `--surface: oklch(100% 0 0)`
- `--fg: oklch(22% 0.02 240)`
- `--muted: oklch(50% 0.018 240)`
- `--border: oklch(90% 0.008 240)`
- `--accent: oklch(58% 0.16 145)`

## Type

- Display and body: `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- Numeric and mono: `ui-monospace, "SFMono-Regular", Consolas, monospace`

## Posture

- Dense, left-aligned administrative composition.
- Existing borders and subtle surfaces define hierarchy; no gradients or decorative imagery.
- Green is reserved for primary actions and selected navigation.
- Status meaning is always carried by literal text as well as colour.
- Motion is limited to immediate interaction feedback.
