One shell contract for the staff POS workspace and one for the admin back office, plus the shared control and state-cue conventions both workspaces answer to. This is an implementation reference, not a pixel target.

No business day is open

Open the business day before recording counts, cash, or sales. Order History stays available because it reads closed days.

What the strip encodes

Fixed order
Sell, Open Day, Opening, Restock, Deliveries & Wastage, Order History, Cash & Expenses, Closing, Close Day. Hairline separators group the day-bracketing actions away from the shift work without moving any destination.
Current destination
aria-current="page", a 3px inset bar on the leading edge, and a heavier label weight. Remove all colour and the current item is still the only one with a bar.
Unavailable destination
The same element with href removed, plus role="link" and aria-disabled="true". An anchor without href is not focusable and not activatable, so the destination is announced and named, skipped by Tab, and cannot navigate. The cue is a lock glyph plus a dashed outline plus appended screen-reader text naming the unmet prerequisite. It carries no fill, no shadow, and no pointer cursor, so it does not read as tappable.
Overflow
The strip scrolls horizontally inside its own bounds (overflow-x: auto on the nav, nothing wider than 100% on any ancestor). The page never scrolls sideways at 1024 or 390.

Admin back-office shell

The admin sidebar is the only navigation on admin routes and never appears on staff routes. Groups stay Workspace, Catalog, Operations. Seven destinations, seven distinct meaningful icons, replacing the five repeated decorative grid marks shipped today.

What the sidebar encodes

Current destination
aria-current="page", a 3px inset bar on the leading edge, and a heavier label weight. The same non-colour vocabulary as the staff strip, rotated to the vertical axis.
Icons
Seven distinct glyphs, one per destination, drawn on the shipped Icon geometry (24 box, 1.8 stroke, currentColor). If distinct glyphs are not funded, the correct alternative is no icons at all. Repeating one decorative mark across five destinations is the state being corrected.
Narrow width
Below 800 px of shell width the sidebar becomes a compact header with the same seven destinations in the same order, scrolling horizontally within its own bounds. Group labels are retained as inline separators rather than dropped, so grouping survives the collapse.

Shared control and state-cue conventions

One vocabulary, both workspaces. The staff workspace uses the taller 48 px control body because it is operated standing at a counter; the admin workspace uses the same hierarchy at back-office density. Hierarchy, wording, and non-colour cues are identical.

Action hierarchy

One primary per view. Destructive is never the primary and always names its object.

Disabled state carries a lock glyph, a flat fill, and a aria-describedby reason. Never grey alone.

Loading

Region marked aria-busy="true", a polite live region carrying the words, and skeleton blocks shaped like the content that will land. Motion is decoration; the text is the state.

No movements recorded yet

Deliveries and wastage appended to this business day will appear here in the order they were recorded.

Error

role="alert", focusable, a triangle glyph, a solid leading rule, and a recovery action. Red reinforces; it never carries the meaning alone.

Success

role="status", a check glyph, a solid leading rule, and a sentence naming the recorded fact. Success is a receipt, not a colour.
