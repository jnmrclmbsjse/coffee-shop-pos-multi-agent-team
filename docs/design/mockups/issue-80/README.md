# UCM Coffee Studio Admin mockup

Open `index.html` in a modern browser. No build step or network connection is required.

## Included review paths

- Switch between Dashboard and Reports from the app navigation.
- Dashboard states: Current day, Latest closed, No data.
- Reports states: Populated, Invalid range, Empty range.
- Edit report dates, apply a valid range, and export a CSV.
- Expand the dashboard sales values table for a text equivalent to the chart.

## Files

- `index.html`: semantic application shell and screen markup
- `styles.css`: exact UCM tokens, responsive layout, and accessible states
- `app.js`: state switching, range validation, populated/empty rendering, and CSV download
- `PRODUCT.md`: product intent and operating principles
- `DESIGN.md`: visual and interaction rules
- `brand-spec.md`: canonical UCM tokens

All figures are labeled sample data for design and QA review.
